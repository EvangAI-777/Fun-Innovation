# Revival

New work for the OvertaleRPG revival. Everything in this directory is original or adapted from the public archive with modifications.

## Structure

```
Revival/
|-- Design/          Game design docs, scope documents, revival roadmap
|-- Scripts/         Dialogue scripts, cutscene scripts, narrative outlines
|-- Assets/
|   |-- Sprites/     Character sprites, enemy sprites, NPC sprites
|   |-- Music/       New or adapted soundtrack files
|   |-- Tilesets/    Environment tilesets, terrain, interiors
|   |-- UI/          Menus, HUD elements, dialogue boxes, fonts
|-- Engine/          Game engine code, systems, tools
|-- Builds/          Playable builds and exports
```

## Design First

Before any code or assets go in here, the Design folder needs to be populated with:

1. A revival scope document (what ships and what doesn't)
2. A converted/annotated version of the original GDD with revival notes
3. A technical plan (engine choice, target platforms, toolchain)
4. A narrative outline (what story beats survive, what gets rewritten)

The original team's mistake was building before scoping. We don't repeat that.
